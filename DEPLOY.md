# Deploy

A documentação de deploy foi organizada em páginas separadas:

- [Instalação em VPS](docs/INSTALACAO.md) — passo a passo de produção.
- [Operação](docs/OPERACAO.md) — atualização, backup, restauração e logs.
- [Segurança](docs/SEGURANCA.md) — senha, token, backups e checklist.

O caminho recomendado é uma VPS Linux com Docker + Caddy. Para testar em um
sandbox sem portas públicas, veja a seção **Instabox** em
[Instalação](docs/INSTALACAO.md#10-instabox--sandbox-opcional).
